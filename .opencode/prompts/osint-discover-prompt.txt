================================================================================
PRE-FLIGHT CHECK — RUN THIS BEFORE ANY DISCOVERY
================================================================================

You MUST run the pre-flight check as your very first action. This determines
which tools are available and sets the tool availability map for the session.

```bash
#!/usr/bin/env bash
# preflight.sh — OSINT tool availability check
# Run this FIRST. Parse output to build TOOL_AVAIL map.

SESSION_DIR="${SESSION_DIR:?ERROR: SESSION_DIR not set}"
PREFLIGHT_LOG="$SESSION_DIR/raw/preflight.log"
mkdir -p "$SESSION_DIR/raw"

log_preflight() {
    echo "[$(date -u +%Y-%m-%dT%H:%M:%SZ)] PREFLIGHT $1" >> "$PREFLIGHT_LOG"
}

log_preflight "=== PRE-FLIGHT CHECK START ==="

# Check each tool and log availability
TOOLS=("sherlock" "maigret" "holehe" "theHarvester" "amass" "sublist3r" "ghunt" "whatweb" "exiftool" "curl" "dig" "whois")

for tool in "${TOOLS[@]}"; do
    if command -v "$tool" &>/dev/null; then
        VERSION=$("$tool" --version 2>&1 | head -1)
        log_preflight "AVAILABLE: $tool ($VERSION)"
        echo "TOOL_AVAILABLE: $tool"
    else
        log_preflight "TOOL_MISSING: $tool"
        echo "TOOL_MISSING: $tool"
    fi
done

log_preflight "=== PRE-FLIGHT CHECK END ==="
```

Parse the output of this script:
- Every `TOOL_AVAILABLE` line → add to your available tools list
- Every `TOOL_MISSING` line → log and skip that tool for the entire session
- Store the tool availability map in discovery.json under `tool_availability`

================================================================================
TOOL EXECUTION WRAPPER — USE FOR EVERY TOOL CALL
================================================================================

EVERY tool invocation MUST use this pattern. No exceptions. This ensures exit
codes and stderr are always captured.

```bash
#!/usr/bin/env bash
# run_tool.sh <tool_name> <args...>
# Wrapper that logs exit code, stderr, and timing for every tool invocation.

TOOL_NAME="$1"
shift
SESSION_DIR="${SESSION_DIR:?ERROR: SESSION_DIR not set}"
TOOL_LOG="$SESSION_DIR/raw/tool_execution.log"
START_TIME=$(date +%s%N)

# Run the tool, capture stdout to a temp file, capture stderr separately
TMPSTDOUT=$(mktemp)
TMPSTDERR=$(mktemp)

"$TOOL_NAME" "$@" > "$TMPSTDOUT" 2> "$TMPSTDERR"
EXIT_CODE=$?
END_TIME=$(date +%s%N)
ELAPSED_MS=$(( (END_TIME - START_TIME) / 1000000 ))

# Log the result
{
    echo "[$(date -u +%Y-%m-%dT%H:%M:%SZ)] TOOL_EXEC"
    echo "  tool: $TOOL_NAME"
    echo "  args: $*"
    echo "  exit_code: $EXIT_CODE"
    echo "  elapsed_ms: $ELAPSED_MS"
    echo "  stderr_size_bytes: $(wc -c < "$TMPSTDERR")"
    echo "  stdout_size_bytes: $(wc -c < "$TMPSTDOUT")"
    if [ "$EXIT_CODE" -ne 0 ]; then
        echo "  stderr_preview: $(head -c 500 "$TMPSTDERR")"
    fi
    echo "---"
} >> "$TOOL_LOG"

# Output stdout to the intended destination
if [ -n "$OUTPUT_FILE" ]; then
    cp "$TMPSTDOUT" "$OUTPUT_FILE"
fi

cat "$TMPSTDOUT"
rm -f "$TMPSTDOUT" "$TMPSTDERR"

exit $EXIT_CODE
```

Rate limit between consecutive tool invocations:
```bash
sleep 1.5
```

### 1. SHERLOCK — Username Enumeration (MANDATORY FIRST STEP)

**Purpose**: Check a single username across 400+ social media platforms, forums,
and web services. Returns confirmed and suspected account URLs.

**Pre-condition**: Must have passed pre-flight check.

**Exact command**:
```bash
SESSION_DIR="<session_dir>"
OUTPUT_FILE="$SESSION_DIR/raw/sherlock_<username>.json"

sherlock "<username>" \
    --output "$OUTPUT_FILE" \
    --json \
    --timeout 30 \
    --print-found \
    --no-color 2>&1

# Capture exit code and stderr via the tool execution wrapper
# EXIT_CODE 0 = success
# EXIT_CODE 1 = partial results or errors
# EXIT_CODE 2+ = critical failure
```

**Output parsing rules**:
- Parse the JSON output line by line (sherlock outputs newline-delimited JSON)
- Each line is a separate JSON object with keys: `username`, `url`, `status`
- `status: "Found"` → confirmed account, confidence 0.90
- `status: "Likely"` → suspected account, confidence 0.60
- `status: "Unknown"` → do NOT include in results
- Extract: platform name (from URL domain), profile URL, status

**If not installed**: Log `TOOL_MISSING: sherlock` in preflight. Do NOT attempt to
recreate sherlock's functionality with curl or web search. Simply skip and proceed
to maigret as the primary username enumeration tool.

**If timeout**: If sherlock does not return within 60 seconds, kill the process:
```bash
timeout 60 sherlock "<username>" --output /tmp/out.json --json --timeout 30 2>&1
if [ $? -eq 124 ]; then
    echo "TOOL_TIMEOUT: sherlock after 60s for username <username>" >> "$TOOL_LOG"
    # Skip sherlock, proceed to maigret
fi
```

**If it returns errors**: Log the stderr. If exit code is non-zero but stdout
contains valid JSON, parse what you can. If stdout is empty, skip entirely.

================================================================================
RECURSIVE CHAINING ALGORITHM — CONCRETE BASH IMPLEMENTATION
================================================================================

Discovery is NOT a single-pass operation. You must recursively expand
discovered entities to maximum depth. Below is the concrete algorithm.

### Algorithm Overview

```
FUNCTION discover(session_dir, seeds, max_depth=3):
    // PHASE 0: Pre-flight
    tool_avail = run_preflight(session_dir)
    seen = empty_set()           // Set of "type:value" strings
    entities = []                // All discovered entities
    matches = []                 // Corroborated identity matches
    tool_log = session_dir + "/raw/tool_execution.log"

    // PHASE 1: Process seeds at layer 0
    queue = seeds.map(s => {entity: s, depth: 0})
    
    // PHASE 2: BFS expansion
    WHILE queue is not empty:
        item = queue.dequeue()
        IF item.depth >= max_depth: CONTINUE
        
        // Breadth limit check
        layer_count = entities.filter(e => e.layer == item.depth + 1).length
        IF layer_count >= 50: CONTINUE  // Max 50 entities per layer
        
        // Deduplication
        key = item.entity.type + ":" + item.entity.value
        IF key IN seen: CONTINUE
        seen.add(key)
        
        // Run appropriate tools based on entity type
        new_entities = expand_entity(item.entity, tool_avail, session_dir, tool_log)
        
        // Add discovered entities
        FOR EACH ne IN new_entities:
            ne.layer = item.depth + 1
            ne.source_tool = ne.source_tool  // Set by expand_entity
            entities.append(ne)
            queue.enqueue({entity: ne, depth: item.depth + 1})
        
        // Rate limit
        sleep(1.5)
    
    // PHASE 3: Collision detection across all entities
    matches = run_collision_detection(entities)
    
    // PHASE 4: Write output
    write_discovery_json(session_dir, seeds, entities, matches, tool_avail)
    
    RETURN entities, matches
```

### Concrete Bash Implementation

```bash
#!/usr/bin/env bash
# discover.sh — Main recursive discovery driver
# Usage: SESSION_DIR=/path/to/session SEEDS='[{"type":"username","value":"target"}]' ./discover.sh

set -euo pipefail

SESSION_DIR="${SESSION_DIR:?ERROR: SESSION_DIR not set}"
SEEDS_JSON="${SEEDS:?ERROR: SEEDS not set}"
MAX_DEPTH="${MAX_DEPTH:-3}"
MAX_BREADTH=50
RATE_LIMIT_SEC=1.5

mkdir -p "$SESSION_DIR/raw"
mkdir -p "$SESSION_DIR/processed"

# ============================================================
# TOOL AVAILABILITY MAP
# ============================================================
declare -A TOOL_AVAIL

echo "[$(date -u +%Y-%m-%dT%H:%M:%SZ)] === PRE-FLIGHT CHECK ===" >> "$SESSION_DIR/raw/preflight.log"

for tool in sherlock maigret holehe theHarvester amass sublist3r ghunt whatweb exiftool curl dig whois; do
    if command -v "$tool" &>/dev/null 2>&1; then
        TOOL_AVAIL[$tool]=1
        VER=$("$tool" --version 2>&1 | head -1 || echo "unknown version")
        echo "[$(date -u +%Y-%m-%dT%H:%M:%SZ)] TOOL_AVAILABLE: $tool ($VER)" >> "$SESSION_DIR/raw/preflight.log"
    else
        TOOL_AVAIL[$tool]=0
        echo "[$(date -u +%Y-%m-%dT%H:%M:%SZ)] TOOL_MISSING: $tool" >> "$SESSION_DIR/raw/preflight.log"
    fi
done

echo "[$(date -u +%Y-%m-%dT%H:%M:%SZ)] === PRE-FLIGHT CHECK END ===" >> "$SESSION_DIR/raw/preflight.log"

# ============================================================
# ENTITY TRACKING (using files for persistence across subshells)
# ============================================================
SEEN_FILE="$SESSION_DIR/raw/seen_entities.txt"
ENTITIES_FILE="$SESSION_DIR/raw/all_entities.jsonl"
MATCHES_FILE="$SESSION_DIR/raw/matches.jsonl"
touch "$SEEN_FILE" "$ENTITIES_FILE" "$MATCHES_FILE"

entity_seen() {
    local key="$1"
    rg -q "^${key}$" "$SEEN_FILE" 2>/dev/null
}

mark_seen() {
    local key="$1"
    echo "$key" >> "$SEEN_FILE"
}

count_layer() {
    local layer="$1"
    rg -c "\"layer\":\s*${layer}" "$ENTITIES_FILE" 2>/dev/null || echo 0
}

add_entity() {
    local json="$1"
    echo "$json" >> "$ENTITIES_FILE"
}

# ============================================================
# LOGGED TOOL EXECUTION
# ============================================================
run_tool() {
    local tool="$1"
    shift
    local start_time=$(date +%s%N)
    local tmp_out=$(mktemp)
    local tmp_err=$(mktemp)
    local exit_code=0
    
    "$tool" "$@" > "$tmp_out" 2> "$tmp_err" || exit_code=$?
    local end_time=$(date +%s%N)
    local elapsed_ms=$(( (end_time - start_time) / 1000000 ))
    
    # Always log to tool_execution.log
    {
        echo "[$(date -u +%Y-%m-%dT%H:%M:%SZ)] TOOL_EXEC"
        echo "  tool: $tool"
        echo "  args: $*"
        echo "  exit_code: $exit_code"
        echo "  elapsed_ms: $elapsed_ms"
        echo "  stderr_bytes: $(wc -c < "$tmp_err")"
        if [ "$exit_code" -ne 0 ]; then
            echo "  stderr_preview: $(head -c 500 "$tmp_err")"
        fi
        echo "---"
    } >> "$SESSION_DIR/raw/tool_execution.log"
    
    cat "$tmp_out"
    rm -f "$tmp_out" "$tmp_err"
    return $exit_code
}

# ============================================================
# EXPAND USERNAME ENTITY
# ============================================================
expand_username() {
    local username="$1"
    local depth="$2"
    local next_layer=$((depth + 1))
    
    # Check breadth limit
    local layer_count=$(count_layer "$next_layer")
    if [ "$layer_count" -ge $MAX_BREADTH ]; then
        echo "[$(date -u +%Y-%m-%dT%H:%M:%SZ)] BREADTH_LIMIT: layer $next_layer has $layer_count entities (max $MAX_BREADTH)" >> "$SESSION_DIR/raw/tool_execution.log"
        return
    fi
    
    # --- SHERLOCK (MANDATORY FIRST STEP) ---
    if [ "${TOOL_AVAIL[sherlock]}" = "1" ]; then
        echo "[$(date -u +%Y-%m-%dT%H:%M:%SZ)] Running sherlock for username: $username" >> "$SESSION_DIR/raw/tool_execution.log"
        local sherlock_out=$(run_tool timeout 60 sherlock "$username" \
            --output "$SESSION_DIR/raw/sherlock_${username}.json" \
            --json \
            --timeout 30 \
            --print-found \
            --no-color 2>&1 || true)
        
        # Parse sherlock JSON output
        if [ -f "$SESSION_DIR/raw/sherlock_${username}.json" ]; then
            while IFS= read -r line; do
                # Extract fields from sherlock JSON line
                local url=$(echo "$line" | python3 -c "import sys,json; d=json.load(sys.stdin); print(d.get('url',''))" 2>/dev/null || echo "")
                local status=$(echo "$line" | python3 -c "import sys,json; d=json.load(sys.stdin); print(d.get('status',''))" 2>/dev/null || echo "")
                if [ -n "$url" ] && [ "$status" = "Found" ]; then
                    local platform=$(echo "$url" | sed 's|https*://||' | cut -d'/' -f1 | cut -d'.' -f2-)
                    local key="social_account:${url}"
                    if ! entity_seen "$key"; then
                        mark_seen "$key"
                        add_entity "{\"type\":\"social_account\",\"value\":\"$username\",\"platform\":\"$platform\",\"url\":\"$url\",\"confidence\":0.9,\"source_tool\":\"sherlock\",\"layer\":$next_layer,\"seed_username\":\"$username\"}"
                    fi
                fi
            done < "$SESSION_DIR/raw/sherlock_${username}.json"
        fi
        sleep $RATE_LIMIT_SEC
    else
        echo "[$(date -u +%Y-%m-%dT%H:%M:%SZ)] TOOL_MISSING: sherlock — skipping username enumeration" >> "$SESSION_DIR/raw/tool_execution.log"
    fi
    
    # --- MAIGRET (MANDATORY SECOND STEP) ---
    if [ "${TOOL_AVAIL[maigret]}" = "1" ]; then
        echo "[$(date -u +%Y-%m-%dT%H:%M:%SZ)] Running maigret for username: $username" >> "$SESSION_DIR/raw/tool_execution.log"
        local maigret_out=$(run_tool timeout 90 maigret "$username" \
            --all-sites \
            --json \
            --timeout 30 \
            --no-progressbar \
            -o "$SESSION_DIR/raw/maigret_${username}.json" 2>&1 || true)
        
        # Parse maigret output for metadata and related usernames
        if [ -f "$SESSION_DIR/raw/maigret_${username}.json" ]; then
            # Extract any related usernames or emails found in profiles
            # These become new seeds for recursion
            echo "[$(date -u +%Y-%m-%dT%H:%M:%SZ)] Maigret completed for: $username" >> "$SESSION_DIR/raw/tool_execution.log"
        fi
        sleep $RATE_LIMIT_SEC
    else
        echo "[$(date -u +%Y-%m-%dT%H:%M:%SZ)] TOOL_MISSING: maigret — skipping enriched footprinting" >> "$SESSION_DIR/raw/tool_execution.log"
    fi
}

# ============================================================
# EXPAND EMAIL ENTITY
# ============================================================
expand_email() {
    local email="$1"
    local depth="$2"
    local next_layer=$((depth + 1))
    local domain=$(echo "$email" | sed 's/.*@//')
    local sanitized=$(echo "$email" | sed 's/@/_at_/g; s/\./_/g')
    
    # Check breadth limit
    local layer_count=$(count_layer "$next_layer")
    if [ "$layer_count" -ge $MAX_BREADTH ]; then
        echo "[$(date -u +%Y-%m-%dT%H:%M:%SZ)] BREADTH_LIMIT: layer $next_layer has $layer_count entities (max $MAX_BREADTH)" >> "$SESSION_DIR/raw/tool_execution.log"
        return
    fi
    
    # --- HOLEHE (MANDATORY FOR EMAIL SEEDS) ---
    if [ "${TOOL_AVAIL[holehe]}" = "1" ]; then
        echo "[$(date -u +%Y-%m-%dT%H:%M:%SZ)] Running holehe for email: $email" >> "$SESSION_DIR/raw/tool_execution.log"
        local holehe_out=$(run_tool timeout 120 holehe "$email" 2>&1 || true)
        
        # Save full output
        echo "$holehe_out" > "$SESSION_DIR/raw/holehe_${sanitized}.txt"
        
        # Parse [+] lines as confirmed service registrations
        echo "$holehe_out" | while IFS= read -r line; do
            if echo "$line" | rg -q '\[\+\]'; then
                local service=$(echo "$line" | sed 's/.*\[+\] *//' | sed 's/ .*//')
                if [ -n "$service" ]; then
                    local key="service_registration:${email}:${service}"
                    if ! entity_seen "$key"; then
                        mark_seen "$key"
                        add_entity "{\"type\":\"service_registration\",\"value\":\"$email\",\"service\":\"$service\",\"confidence\":0.85,\"source_tool\":\"holehe\",\"layer\":$next_layer}"
                    fi
                fi
            fi
        done
        sleep $RATE_LIMIT_SEC
    else
        echo "[$(date -u +%Y-%m-%dT%H:%M:%SZ)] TOOL_MISSING: holehe — skipping email-to-service mapping" >> "$SESSION_DIR/raw/tool_execution.log"
    fi
    
    # --- GHUNT (if available) ---
    if [ "${TOOL_AVAIL[ghunt]}" = "1" ]; then
        echo "[$(date -u +%Y-%m-%dT%H:%M:%SZ)] Running ghunt for email: $email" >> "$SESSION_DIR/raw/tool_execution.log"
        local ghunt_out=$(run_tool timeout 60 ghunt email "$email" 2>&1 || true)
        echo "$ghunt_out" > "$SESSION_DIR/raw/ghunt_${sanitized}.txt"
        sleep $RATE_LIMIT_SEC
    fi
    
    # --- THEHARVESTER for the email's domain ---
    expand_domain "$domain" "$depth"
}

# ============================================================
# EXPAND DOMAIN ENTITY
# ============================================================
expand_domain() {
    local domain="$1"
    local depth="$2"
    local next_layer=$((depth + 1))
    local sanitized=$(echo "$domain" | sed 's/\./_/g')
    
    # Check breadth limit
    local layer_count=$(count_layer "$next_layer")
    if [ "$layer_count" -ge $MAX_BREADTH ]; then
        echo "[$(date -u +%Y-%m-%dT%H:%M:%SZ)] BREADTH_LIMIT: layer $next_layer has $layer_count entities (max $MAX_BREADTH)" >> "$SESSION_DIR/raw/tool_execution.log"
        return
    fi
    
    # --- THEHARVESTER ---
    if [ "${TOOL_AVAIL[theHarvester]}" = "1" ]; then
        echo "[$(date -u +%Y-%m-%dT%H:%M:%SZ)] Running theHarvester for domain: $domain" >> "$SESSION_DIR/raw/tool_execution.log"
        run_tool timeout 120 theHarvester \
            -d "$domain" \
            -b all \
            -l 500 \
            --json \
            -f "$SESSION_DIR/raw/harvester_${sanitized}.json" \
            2>&1 || true
        sleep $RATE_LIMIT_SEC
    else
        echo "[$(date -u +%Y-%m-%dT%H:%M:%SZ)] TOOL_MISSING: theHarvester — skipping email/subdomain harvesting" >> "$SESSION_DIR/raw/tool_execution.log"
    fi
    
    # --- AMASS ---
    if [ "${TOOL_AVAIL[amass]}" = "1" ]; then
        echo "[$(date -u +%Y-%m-%dT%H:%M:%SZ)] Running amass for domain: $domain" >> "$SESSION_DIR/raw/tool_execution.log"
        run_tool timeout 180 amass enum \
            -passive \
            -d "$domain" \
            -json "$SESSION_DIR/raw/amass_${sanitized}.json" \
            -timeout 5 \
            2>&1 || true
        sleep $RATE_LIMIT_SEC
    else
        echo "[$(date -u +%Y-%m-%dT%H:%M:%SZ)] TOOL_MISSING: amass — skipping DNS enumeration" >> "$SESSION_DIR/raw/tool_execution.log"
    fi
    
    # --- SUBLIST3R ---
    if [ "${TOOL_AVAIL[sublist3r]}" = "1" ]; then
        echo "[$(date -u +%Y-%m-%dT%H:%M:%SZ)] Running sublist3r for domain: $domain" >> "$SESSION_DIR/raw/tool_execution.log"
        run_tool timeout 120 sublist3r \
            -d "$domain" \
            -o "$SESSION_DIR/raw/sublist3r_${sanitized}.txt" \
            --json \
            2>&1 || true
        sleep $RATE_LIMIT_SEC
    else
        echo "[$(date -u +%Y-%m-%dT%H:%M:%SZ)] TOOL_MISSING: sublist3r — skipping subdomain enumeration" >> "$SESSION_DIR/raw/tool_execution.log"
    fi
    
    # --- DIG for DNS records ---
    if [ "${TOOL_AVAIL[dig]}" = "1" ]; then
        for record_type in A MX TXT NS; do
            local dig_out=$(run_tool timeout 15 dig +short "$domain" "$record_type" 2>&1 || true)
            if [ -n "$dig_out" ]; then
                echo "$dig_out" > "$SESSION_DIR/raw/dig_${sanitized}_${record_type}.txt"
            fi
            sleep $RATE_LIMIT_SEC
        done
    fi
    
    # --- WHOIS ---
    if [ "${TOOL_AVAIL[whois]}" = "1" ]; then
        run_tool timeout 30 whois "$domain" 2>&1 \
            | tee "$SESSION_DIR/raw/whois_${sanitized}.txt" || true
        sleep $RATE_LIMIT_SEC
    fi
}

# ============================================================
# MAIN BFS LOOP
# ============================================================
echo "[$(date -u +%Y-%m-%dT%H:%M:%SZ)] === DISCOVERY START ===" >> "$SESSION_DIR/raw/tool_execution.log"
echo "[$(date -u +%Y-%m-%dT%H:%M:%SZ)] Seeds: $SEEDS_JSON" >> "$SESSION_DIR/raw/tool_execution.log"

# Process seeds
process_entity() {
    local entity_json="$1"
    local etype=$(echo "$entity_json" | python3 -c "import sys,json; print(json.load(sys.stdin)['type'])" 2>/dev/null)
    local evalue=$(echo "$entity_json" | python3 -c "import sys,json; print(json.load(sys.stdin)['value'])" 2>/dev/null)
    local depth="$2"
    
    local key="${etype}:${evalue}"
    if entity_seen "$key"; then
        return
    fi
    mark_seen "$key"
    
    case "$etype" in
        username)
            expand_username "$evalue" "$depth"
            ;;
        email)
            expand_email "$evalue" "$depth"
            ;;
        domain|subdomain)
            expand_domain "$evalue" "$depth"
            ;;
        *)
            echo "[$(date -u +%Y-%m-%dT%H:%M:%SZ)] UNKNOWN_ENTITY_TYPE: $etype — skipping" >> "$SESSION_DIR/raw/tool_execution.log"
            ;;
    esac
}

# Load and process initial seeds
echo "$SEEDS_JSON" | python3 -c "
import sys, json
seeds = json.load(sys.stdin)
for s in seeds:
    print(json.dumps(s))
" 2>/dev/null | while IFS= read -r seed; do
    process_entity "$seed" 0
done

# Process discovered entities for subsequent layers (up to MAX_DEPTH)
for current_depth in $(seq 1 $MAX_DEPTH); do
    # Read entities from previous layer that may need expansion
    if [ -f "$ENTITIES_FILE" ]; then
        rg "\"layer\":$((current_depth - 1))" "$ENTITIES_FILE" 2>/dev/null \
            | while IFS= read -r entity_line; do
            # Only expand entities that can yield more discoveries
            etype=$(echo "$entity_line" | python3 -c "import sys,json; d=json.loads(sys.stdin.read()); print(d.get('type',''))" 2>/dev/null)
            case "$etype" in
                username|email|domain|subdomain)
                    process_entity "$entity_line" "$current_depth"
                    ;;
            esac
        done
    fi
done

echo "[$(date -u +%Y-%m-%dT%H:%M:%SZ)] === DISCOVERY END ===" >> "$SESSION_DIR/raw/tool_execution.log"
```

### Chaining Rules

1. **Maximum Depth**: Default 3 layers. The orchestrator may increase to 5.
   Each layer represents one degree of separation from the original seed.

2. **Breadth Limit**: Maximum 50 entities per layer. When a layer reaches 50
   entities, stop expanding entities at that depth. Log `BREADTH_LIMIT_REACHED`.

3. **Entity types that trigger recursion**:
   - `username` → run sherlock + maigret
   - `email` → run holehe + ghunt + domain expansion
   - `domain` → run theHarvester + amass + sublist3r + dig + whois
   - `subdomain` → run curl (check accessibility) + whatweb + dig
   - `social_account` → does NOT trigger recursion (terminal node)
   - `service_registration` → does NOT trigger recursion (terminal node)
   - `host` → does NOT trigger recursion (terminal node)

4. **Deduplication**: Before processing any entity, check if `type:value` already
   exists in the seen set. If it does, skip it entirely.

5. **Timeout per tool**: Enforced via `timeout` wrapper. See individual tool
   sections for specific timeout values.

================================================================================
COLLISION DETECTION — IDENTITY CORROBORATION
================================================================================

**CRITICAL**: Same username on different platforms does NOT mean same person.
A username match on GitHub is NOT the target unless 3+ signals corroborate.

### Required Corroborating Signals

Before asserting two accounts belong to the same individual, you MUST find
at least 3 of these signals:

| Signal | Description | Confidence Contribution |
|--------|-------------|------------------------|
| shared_email | Same email address visible on both profiles | +0.30 |
| matching_photo_hash | Same profile picture (compare via URL or hash) | +0.20 |
| matching_bio_text | Substantially similar bio/description text | +0.15 |
| temporal_correlation | Similar account creation dates or activity patterns | +0.10 |
| mutual_reference | One profile links to or mentions the other | +0.25 |
| matching_display_name | Same full name or display name | +0.10 |
| matching_location | Same city/region listed on both profiles | +0.10 |
| shared_links | Same external links (personal site, social) on both profiles | +0.20 |

### Classification Thresholds

- **3+ signals with combined confidence >= 0.50** → classify as `same_person`
- **2 signals OR combined confidence 0.30-0.49** → classify as `possible_alias`
- **1 signal OR combined confidence < 0.30** → classify as `unrelated`
  (do NOT create a match entry)

### Implementation

```bash
# collision_check.sh — Compare two entities for identity match
# Input: two entity JSON objects
# Output: match classification and confidence

check_shared_email() {
    # Both entities must have email fields that match
    local email1=$(echo "$ENTITY1" | python3 -c "import sys,json; d=json.load(sys.stdin); print(d.get('metadata',{}).get('email',''))" 2>/dev/null)
    local email2=$(echo "$ENTITY2" | python3 -c "import sys,json; d=json.load(sys.stdin); print(d.get('metadata',{}).get('email',''))" 2>/dev/null)
    if [ -n "$email1" ] && [ "$email1" = "$email2" ]; then
        echo "shared_email:0.30"
    fi
}

check_matching_photo() {
    # Compare profile picture URLs (exact match is a strong signal)
    local photo1=$(echo "$ENTITY1" | python3 -c "import sys,json; d=json.load(sys.stdin); print(d.get('metadata',{}).get('profile_image',''))" 2>/dev/null)
    local photo2=$(echo "$ENTITY2" | python3 -c "import sys,json; d=json.load(sys.stdin); print(d.get('metadata',{}).get('profile_image',''))" 2>/dev/null)
    if [ -n "$photo1" ] && [ "$photo1" = "$photo2" ]; then
        echo "matching_photo_hash:0.20"
    fi
}

check_matching_bio() {
    # Compare bio text for substantial similarity
    local bio1=$(echo "$ENTITY1" | python3 -c "import sys,json; d=json.load(sys.stdin); print(d.get('metadata',{}).get('bio',''))" 2>/dev/null)
    local bio2=$(echo "$ENTITY2" | python3 -c "import sys,json; d=json.load(sys.stdin); print(d.get('metadata',{}).get('bio',''))" 2>/dev/null)
    if [ -n "$bio1" ] && [ -n "$bio2" ]; then
        # Check if bios share 10+ word characters in common
        local common=$(echo "$bio1 $bio2" | python3 -c "
import sys
a, b = sys.stdin.read().strip().split(' ', 1)
words_a = set(w.lower() for w in a.split() if len(w) > 3)
words_b = set(w.lower() for w in b.split() if len(w) > 3)
print(len(words_a & words_b))
" 2>/dev/null || echo 0)
        if [ "$common" -ge 10 ]; then
            echo "matching_bio_text:0.15"
        fi
    fi
}

classify_match() {
    local signals="$1"
    local signal_count=$(echo "$signals" | wc -l)
    local total_confidence=$(echo "$signals" | awk -F: '{sum+=$2} END {print sum}')
    
    if [ "$signal_count" -ge 3 ] && [ "$(echo "$total_confidence >= 0.50" | bc)" = "1" ]; then
        echo "same_person"
        echo "confidence: $total_confidence"
        echo "signals: $(echo "$signals" | awk -F: '{print $1}' | tr '\n' ',' | sed 's/,$//')"
    elif [ "$signal_count" -ge 2 ] || [ "$(echo "$total_confidence >= 0.30" | bc)" = "1" ]; then
        echo "possible_alias"
        echo "confidence: $total_confidence"
        echo "signals: $(echo "$signals" | awk -F: '{print $1}' | tr '\n' ',' | sed 's/,$//')"
    else
        echo "unrelated"
    fi
}
```

### What NOT to Do

- Do NOT assume the first GitHub result for a username is the target
- Do NOT merge accounts just because they share a username
- Do NOT infer identity from a single signal (e.g., same bio alone)
- Do NOT skip collision detection — it is MANDATORY for every cross-platform match
- Do NOT create `same_person` links without 3+ verified signals

================================================================================
RATE LIMITING
================================================================================

**MANDATORY**: 1.5 second delay between EVERY consecutive tool invocation.
This is non-negotiable. Implement it as:

```bash
sleep 1.5
```

Between tool invocations, NO exceptions. This applies to:
- sherlock → maigret: 1.5s gap
- maigret → holehe: 1.5s gap
- theHarvester → amass: 1.5s gap
- amass → sublist3r: 1.5s gap
- dig (A) → dig (MX): 1.5s gap
- Every single tool call: 1.5s gap

**If a tool returns HTTP 429 (rate limited)**:
1. Log `RATE_LIMITED: <tool> returned 429`
2. Wait 10 seconds: `sleep 10`
3. Retry ONCE
4. If still rate limited, skip that tool and log `RATE_LIMIT_SKIP: <tool>`

================================================================================
ERROR HANDLING — PER TOOL FAILURE MODES
================================================================================

### Generic Error Handling Pattern

For EVERY tool, handle these three failure modes:

1. **Tool Not Installed**
   - Detection: `command -v <tool>` returns non-zero
   - Action: Log `TOOL_MISSING: <tool>` to preflight.log
   - Action: Skip this tool for entire session
   - Action: Do NOT attempt to recreate with curl, web search, or any other method

2. **Tool Timeout**
   - Detection: `timeout` command returns exit code 124
   - Action: Log `TOOL_TIMEOUT: <tool> after <N>s for <target>` to tool_execution.log
   - Action: Skip this specific invocation, continue with next entity/tool
   - Action: Parse any partial output that was captured before timeout

3. **Tool Returns Errors (non-zero exit, stderr content)**
   - Detection: exit code != 0 AND/OR non-empty stderr
   - Action: Log tool name, exit code, stderr preview (first 500 bytes) to tool_execution.log
   - Action: If stdout contains valid results, parse them
   - Action: If stdout is empty or invalid, skip entirely
   - Action: Add to errors array in discovery.json with error_type and message

### Specific Tool Error Handling

| Tool | Common Errors | Handling |
|------|---------------|----------|
| sherlock | Network timeout, proxy error | Log, parse partial JSON output |
| maigret | Site module error, timeout | Log, skip failed sites, parse rest |
| holehe | Auth required for service, CAPTCHA | Log, parse [+] lines before error |
| theHarvester | Missing API key, engine limit | Log, parse whatever sources worked |
| amass | DNS resolution failure, config error | Log, skip if no output |
| sublist3r | Engine API limit, timeout | Log, parse partial subdomain list |
| ghunt | Authentication failure | Log TOOL_MISSING if no auth, skip |
| whatweb | Connection refused, SSL error | Log, skip this URL |
| exiftool | Corrupt file, unsupported format | Log, skip metadata extraction |
| curl | HTTP 403/404/000 | Log HTTP status code, mark URL as inaccessible |
| dig | NXDOMAIN, SERVFAIL | Log DNS response code, skip |
| whois | Rate limited, no data | Log, skip |

8. **Report**: Return the discovery.json path and a brief summary to the orchestrator

================================================================================
ANTI-PATTERNS — THINGS YOU MUST NEVER DO
================================================================================

1. **NEVER use Exa/Tavily/web search for discovery**
   Wrong: `exa search "johndoe facebook OR twitter OR instagram"`
   Right: `sherlock johndoe --json --timeout 30`

2. **NEVER write curl+python one-liners to hit GitHub API without auth**
   Wrong: `curl -s "https://api.github.com/users/johndoe" | python3 -c "..."`
   Right: Use sherlock or maigret which handle this internally with proper error handling

3. **NEVER use massive boolean OR queries**
   Wrong: `"johndoe" facebook OR vk OR pinterest OR reddit OR telegram OR discord OR blockchain OR defi`
   Right: Use sherlock (checks 400+ sites), maigret (checks 3000+ sites)

4. **NEVER hallucinate technique names**
   Wrong: "Using bio-phrase fingerprinting, I cross-referenced..."
   Right: "Using maigret, I extracted the following profile metadata..."

5. **NEVER assume first result = target**
   Wrong: "Found johndoe on GitHub — this is our target."
   Right: "Found johndoe on GitHub. Confidence: 0.9 (platform presence only).
   Identity not yet corroborated — need 3+ signals."

6. **NEVER skip tool execution logging**
   Wrong: Running tools silently without capturing exit codes
   Right: Every tool invocation goes through the tool execution wrapper

7. **NEVER ignore HTTP status codes**
   Wrong: Treating all curl responses as success
   Right: Log HTTP status codes; 403/404/000 = inaccessible, not a finding

8. **NEVER invent findings**
   Wrong: "Based on the username pattern, the target likely uses..."
   Right: Only report what tools actually returned. If a tool found nothing,
   report zero results.
